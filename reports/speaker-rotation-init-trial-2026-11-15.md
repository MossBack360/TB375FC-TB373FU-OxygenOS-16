## Owner result and event-driven successor

Owner confirmed the v2.2 audio channel test. Its log recorded rotations 1→0→1→2→3 and corresponding `gsensor_rotation` 0→270→0→90→180. The 2-second `dumpsys window` loop was then considered unnecessary overhead.

Built the event-driven helper from `patch/speaker_rotation_event/` using `patch/build_speaker_rotation_event.py`. It subscribes to `IWindowManager.watchRotation` and invokes the same `AudioSetParam` command only when the rotation changes. AOSP's API contract returns the initial rotation and then calls back for changes. It is a resident but sleeping `app_process`, not a timer loop. The `rom/fixo-speaker-rotation.rc` source artifact uses `sys.boot_completed=1` to start a managed init service. The Magisk `service.sh` is a temporary test adapter.

v2.3 test initially lacked the boot-complete wait. Its process was absent after boot; a manual start after boot worked. This was treated as a boot timing failure, and v2.3 was superseded. v2.4 adds the wait to the Magisk adapter and the matching property trigger to the future ROM RC. v2.4 ZIP: `out/speaker-rotation-init-trial-2026-11-15/fixo-speaker-rotation-event-v2.4-test.zip`, SHA-256 `bc780712e6b57c54b4ff39f89eb7b2bcabf769f3a0344427a6c5cc4cedfed9b3`. Installed under the same module ID and rebooted. After `sys.boot_completed=1`, PID 4067 was resident and sleeping. Forced rotation 1→0→1 while restoring `cmd window user-rotation` to `free`; logcat recorded `rotation=0 gsensor_rotation=270` and `rotation=1 gsensor_rotation=0`, with no periodic `dumpsys` process. `dumpsys meminfo 4067` reported TOTAL PSS 60,899 KB. Owner audio test for v2.4 has not separately been repeated, but v2.2's same AudioSetParam mapping was confirmed.

Owner tested speaker-rotation v2.4 event-driven module after reboot and confirmed correct channel behavior. The first rotation takes effect; the two forced rotation changes were simply two successful test events, each producing one callback. PSS is proportional set size, an estimate of RAM attributed to the process including its share of common memory; measured about 60,899 KB. Final ROM init/SELinux integration remains pending.
